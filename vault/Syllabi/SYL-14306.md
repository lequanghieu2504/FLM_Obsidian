## Description
1. Course Objectives: This course provides students with the essential computing foundation for Fintech. The course focuses on developing basic programming skills in Python, SQL to analyze data, manage databases, and perform statistical computing, equipping students with the fundamental tools to solve problems and succeed in the fast-growing FinTech industry. By the end of this course, students will gain the technical proficiency needed to support roles in data-driven financial analysis, algorithmic trading, and financial application development. 2. Course Content: Key topics include: Fundamentals of Programming and Data Analysis in Business; Fundamentals of Python programming; Fundamentals of R programming; Foundation of SQL for data management; Integrating Python and SQL. 3. Activities and Teaching Methodology: Lectures, hands-on coding sessions, and individual and group projects to practice the application of programming techniques using Python, SQL enabling them to apply their skills in practical, job-oriented scenarios.
