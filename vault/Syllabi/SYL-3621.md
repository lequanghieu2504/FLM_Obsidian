# SYL-3621

Subject: [[eat201]]
Name: Đánh giá và kiểm tra - Assessment and Testing
Credits: 3
Degree Level: <Bachelor>
Time Allocation: Contact time: 30 sessions; 1 session = 90'
Prerequisite: ETL101
Active: True
Approved: True
Decision: 870/QĐ-ĐHFPT dated 08/06/2021

## Description
Objective: 'This course aims to equip students with an insight into the important inssues of language testing and skills to design questions for language achievement tests of multiple language skills." Teaching method: lecture + acitivities + project works

## Learning Outcomes
| No. | CLO Name | CLO Details |
| --- | --- | --- |
| 1 | CLO1 | Identify different types of language tests and their purposes |
| 2 | CLO2 | Weigh the roles of testing in an EFL course |
| 3 | CLO3 | Evaluate the validity and reliability of a language test based on clear criteria |
| 4 | CLO4 | Construct the specifications for developing a specific test of an EFL course |
| 5 | CLO5 | Design an achievement test for a specific EFL course |
| 6 | CLO6 | Evaluate the beneficial backwash of a test |
