## Description
This course introduces students to the principles and trade-offs in designing data-intensive systems, using Designing Data-Intensive Applications (2nd Edition) as the primary textbook. Students will study: 1. Trade-offs in data systems architecture: OLTP vs OLAP, Cloud vs Self-Hosting, Distributed vs Single-Node systems. 2. Nonfunctional requirements: Scalability, Reliability, and Maintainability. 3. Data models: Relational, Document, and Graph-Like models. 4. Storage and retrieval: LSM-tree, B-Trees, columnar storage, Cloud Data Warehouses. 5. Batch processing: MapReduce and Apache Spark on large-scale public datasets. 6. Stream processing: Change Data Capture (CDC), Kafka/Redpanda, log-based messaging. 7. Data encoding: JSON, Protocol Buffers, Avro, schema evolution. 8. Distributed systems: Replication, Sharding, Transactions, and Isolation. 9. End-to-end data pipeline design from OLTP ingestion to OLAP analytical output.
