## Description
In this course, IoT technology will be applied to the implementation of a real project by using the relevant knowledge. The application of IoT technology in the course through information technology research and application issues includes the steps of collection user requirements, data, analysis and implementation of an IoT project in real life. related to the agricultural sector. The implementation steps will include design, implementation, testing and demonstration related to the field of IoT for agriculture.
