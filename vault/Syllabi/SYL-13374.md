## Description
This course covers the fundamentals of working Ui/Ux (Interaction Design). It’s only a starting point, though. As with any artistic pursuit, (Interaction Design) is a lifelong process of learning.With what you learn in this course forming a solid foundation, you can continue exploring all the complex.
