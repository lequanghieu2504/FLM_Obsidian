## Description
This course is based on the "An Introduction to Programming the Internet of Things (IoT)" Specialization at https://www.coursera.org/specializations/iot. The course covers embedded systems, the Raspberry Pi Platform and the Arduino environment for building devices that can control the physical world. Unlike traditional computer-based systems, IoT devices are “embedded” within other devices in order to provide enhanced functionality without exposing the user to the complexities of a computer. In terms of programming, Arduino - an open-source computer hardware/software platform for building digital devices and interactive objects, is a great choice for controlling small devices, whereas the Raspberry Pi - a small single-board computer, is useful for designing and developing practical IoT devices. Students must complete the IOT102 course before participating in this course. Students will start with a detailed introduction to the internet of things and embedded systems, then work with Arduino and program in C, then work with Raspberry Pi and program in Python, and finally produce a group project. In this final project, students will apply the skills learned by designing, building and testing a microcontroller-based embedded system, completing a unique final project that can be listed as an achievement in their CVs.
