## Description
Upon completion of this course students shoud: 1. Understand the followings: • Basic concepts of Java FX to build Desktop Application • Basics of Object-Relational Mapping (ORM) with Hibernate and how it simplifies database interactions. • Spring Framework, which provides a comprehensive ecosystem for building enterprise-level applications. • Spring Framework's dependency injection, AOP, and web frameworks to build robust and scalable applications 2. Be able to: • Develop Cross-platform Desktop applications and support for user experience (UI & UX) • Use Hibernate as a powerful ORM tool to map Java objects to database tables. • Use Spring Framework's dependency injection, AOP, and web frameworks to build robust and scalable applications. 3. Be able to work in team and present group's results

## Learning Outcomes
| No. | CLO Name | CLO Details |
| --- | --- | --- |
| 1 | CLO1 | Describe the basics of Object-Relational Mapping (ORM) and how it simplifies database interactions. |
| 2 | CLO2 | Create Cross-Platform applications using JavaFX. JavaFX is platform-independent, which means that JavaFX applications (CRUD) can run on different operating systems such as Windows, macOS, and Linux |
| 3 | CLO3 | Describe the concepts of Spring Framework and Spring MVC provides a comprehensive programming and configuration model for modern Java-based enterprise applications. |
| 4 | CLO4 | Create application with Hibernate and Spring Framework. |
| 5 | CLO5 | Develop teamwork skills, communication skills (including presentation skills) |
