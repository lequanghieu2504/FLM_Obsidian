## Description
To provide students with a basic understanding of software engineering and hand-on exercises on writing software project related documents. The following topics will be introduced through the course: - Introduction to software development profession - Software Processes - Agile software development - Requirement Engineering - System Modeling - Architectural Design - Design and implementation - Configuration Management - Software Testing - Software Evolution - Sociotechnical systems - Service-oriented architecture
