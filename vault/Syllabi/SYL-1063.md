## Description
This course covers basic concepts of cloud computing and introduces two strategic cloud computing services of Microsoft and Amazon: Windows Azure and Office 365, Amazon Web Service. At completion of this course, students shall be able to design, develop, and deploy basic applications in Windows Azure and Office 365, Amazon Web Service.
