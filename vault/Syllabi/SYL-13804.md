## Description
Upon completion of this course students shoud: 1. Understand the followings: • Basic concepts of Java FX to build Desktop Application • Basics of Object-Relational Mapping (ORM) with JPA and how it simplifies database interactions. • Spring Framework, Spring Boot, which provides a comprehensive ecosystem for building enterprise-level applications. • Spring Framework's dependency injection, and web frameworks to build robust and scalable applications 2. Be able to: • Use JPA ORM tool to map Java objects to database tables. • Use Spring Framework's dependency injection, and web frameworks to build robust and scalable applications. • Develop Cross-platform Desktop applications and support for user experience (UI & UX) 3. Be able to work in team and present group's results
