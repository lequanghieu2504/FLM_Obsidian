## Description
This course equips students with knowledge of the C++ programming language from basic to advanced, *) Basics - C++ Keywords, C++ Variable Types, Lvalues and Rvalues, Operators in C++, Strings, Arrrays, Pointerts, C++ References, C++ Basic Input/Output ... - OOP *) Advance: C/C++ Standard Template Libaries, Files/streaming ,Exception, template, multithread, smartpointer, etc.

## Learning Outcomes
| No. | CLO Name | CLO Details |
| --- | --- | --- |
| 1 | CLO1 | Understand and apply fundamental concepts of C++ programming to develop basic computational solutions |
| 2 | CLO2 | Effectively manage memory and organize data using advanced C++ programming techniques |
| 3 | CLO3 | Write modular, reusable, and efficient C++ programs using advanced programming techniques and standard libraries. |
| 4 | CLO4 | Apply object-oriented programming principles and techniques in C++ to design robust, modular, and maintainable software solutions. |
| 5 | CLO5 | Apply advanced C++ programming features and file handling techniques to develop flexible and efficient software solutions. |
