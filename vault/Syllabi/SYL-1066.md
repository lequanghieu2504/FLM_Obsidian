## Description
The course is composed of 3 parts: Part 1 is for overview of JAVA technology and strengthening the basic knowledge and skills in java programming language such as using multi- threading programming, GUI programming, processing graphics, Java internationalization utilities Part 2 is for developing Java distributed applications Part 3 is for developing Java database applications

## Learning Outcomes
| No. | CLO Name | CLO Details |
| --- | --- | --- |
| 1 | CLO1 | Discuss the concept of concurrency programming and muti-threading application |
| 2 | CLO2 | Explain the issue of concurrency programming, thread Synchronization and Wait/Notify mechanism |
| 3 | CLO3 | Discuss the role of JFC and Swing and applies the use of swing components to create a GUI application |
| 4 | CLO4 | Applies the use of swing layout for designing a window application |
| 5 | CLO5 | Applies the event handling for writing event listeners for swing components |
| 6 | CLO6 | Explain how to program network application using Socket API and RMI |
| 7 | CLO7 | Demonstrates how to display and print 2D graphics in your Java programs |
| 8 | CLO8 | Demonstrates the use of JDBC to execute common SQL statements, and perform other objectives common to database applications. |
| 9 | CLO9 | Demonstrates how to internationalize Java applications |
