# SYL-11271

Subject: [[DTG302]]
Name: Principles of Compositing _Thiết kế hình ảnh và âm thanh trong làm phim
Credits: 3
Degree Level: Bachelor level
Time Allocation: Study hour (150h) = 45h contact hours + 105h self-study
Prerequisite: None
Active: True
Approved: True
Decision: 358/QĐ-ĐHFPT dated 04/03/2024

## Description
- This course will teach students how to make motion graphics and how to create visual effects using Adobe After Effects software. At the end of the course, students will know how to apply the knowledge of timing, rhythm, composition to create a complete animation product

## Learning Outcomes
| No. | CLO Name | CLO Details |
| --- | --- | --- |
| 1 | CLO1 | Students are able to combine principles of graphic design and motion, and able to create animated graphics which highlight harmony and unity between images and sounds |
| 2 | CLO2 | Understanding the fundamentals of digital animation |
| 3 | CLO3 | Basic design principals as it applies to Motion Graphics |
| 4 | CLO4 | Use After Effects efficiently and effectively |
| 5 | CLO5 | Creatively integrate text, image, video and sound using motion graphics techniques |
| 6 | CLO6 | Create professional animation sequences and composites using a variety of features |
| 7 | CLO7 | Having a professional working style. Practice and develop ethics, professionalism. |
