## Description
This course provides students with practical knowledge and skills to design, deploy, and operate end-to-end MLOps pipelines on cloud platforms (AWS, Azure, Google Cloud). Students will master cloud-native data engineering (S3/GCS, Kafka, Dataflow, Glue), data versioning with DVC, feature stores (Feast, Vertex Feature Store), and scalable model training using distributed GPU/TPU clusters. The curriculum covers CI/CD for ML (GitHub Actions, Jenkins, GitLab CI), containerization with Docker, Kubernetes-based deployment (GKE/EKS/AKS), and production monitoring with Prometheus, Grafana, and cloud-native logging. Through hands-on labs and a final cloud-deployed project, students will gain comprehensive experience in building production-ready ML systems with automated monitoring, drift detection, and retraining pipelines, while addressing cost optimization, security, and compliance (GDPR, HIPAA).

## Learning Outcomes

| --- | --- | --- |
| 1 | CLO1 | Understand core concepts, differences, and relationships among MLOps, DevOps, DataOps, and LLMOps (including RAG & Prompt Engineering basics); apply cloud architecture patterns for ML systems (ingestion, storage, deployment models) across major cloud platforms (AWS SageMaker, Azure ML, Vertex AI). |
| 2 | CLO2 | Design and implement cloud-based data engineering pipelines using cloud-native services (AWS Lambda/Step Functions/Glue, GCP Dataflow/Cloud Composer, Azure Data Factory) and implement feature store management solutions (Feast, Vertex/Azure Feature Store) for offline/online inference. |
| 3 | CLO3 | Apply experiment tracking tools (MLflow, WandB, SageMaker Experiments, Vertex Vizier) and data versioning principles using DVC with cloud remotes (S3/GCS/Azure) to ensure reproducibility, data lineage, and metadata management in ML experiments. |
| 4 | CLO4 | Design and build end-to-end TensorFlow Extended (TFX) and cloud native pipelines (including ExampleGen, Transform, Trainer, Evaluator, Publisher), establish model baselines, and handle concept drift. |
| 5 | CLO5 | Understand feature store concepts and implement feature management solutions using Feast, Vertex Feature Store, or Azure Feature Stores for offline/online inference on cloud. |
| 6 | CLO6 | Apply Docker containerization best practices, build containerized MLOps pipelines to deploy to cloud registries (ECR/GCR/ACR) and services (Cloud Run, ECS, GKE, AKS), and implement model serving patterns (TF Serving, FastAPI, Flask) with progressive delivery (blue-green, canary) and autoscaling (HPA/VPA). |
| 7 | CLO7 | Implement automated CI/CD pipelines for ML using GitHub Actions, Jenkins, or GitLab CI integrated with cloud services to automate model deployments, testing, and continuous validation in cloud environments. |
| 8 | CLO8 | Implement continuous model monitoring (Prometheus, Grafana, Cloud Monitoring) for data/concept drift, setup automated retraining triggers based on performance thresholds, and apply operational excellence principles (incident response, runbooks, rollback, data governance, GDPR, HIPAA, IAM). |
| 9 | CLO9 | Implement an end-to-end Cloud MLOps capstone project encompassing infrastructure setup, automated data pipelines, model tracking, cloud deployment, monitoring, automated retraining, and document it via a scientific/technical paper (4–6 pages) detailing architecture, experiments, ops plan, and cost analysis. |
