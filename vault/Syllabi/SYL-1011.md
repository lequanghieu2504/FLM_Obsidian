# SYL-1011

Subject: [[JPP301]]
Name: Japanese Phonectics
Credits: 3
Degree Level: Bachelor
Time Allocation: "Contact time: 30 sesions 1 session = 90' "
Prerequisite: [[JPD322]]
Active: True
Approved: True
Decision: 1464/QĐ-ĐHFPT dated 09/08/2006

## Description
Nội dung học bao gồm: - Nhịp, phách trong tiếng Nhật - Luyện phát âm (âm dài, âm ngắt, âm ghép) - Cách kiểu lên xuống (intonation, áccent, prominence) trong tiếng Nhật "Assessments Phương thức đánh giá" "1 Tổng: 100% 1.1 Điểm đánh giá trong quá trình: 50% - Tham gia (chuyên cần, nghiêm túc, tích cực xây dựng bài, viết đánh giá ) 20 % - Kiểm tra quá trình: 30% (02 bài) 1.2 Thi cuối kỳ: 50% 2 )Điều kiện hoàn thành học phần: Tổng điểm của mỗi thành phần đánh giá trong quá trình > 0; Điểm thi cuối kỳ >=4/10 và Điểm học phần >= 5/10 thì hoàn thành
