## Description
This course covers the fundamentals of working in CG (Computer Graphic) with Maya. It’s only a starting point, though. As with any artistic pursuit, CG is a lifelong process of learning. With what you learn in this course forming a solid foundation, you can continue exploring all the complex, interesting facets of creating CG imagery
