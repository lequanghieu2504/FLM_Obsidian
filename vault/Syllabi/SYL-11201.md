## Description
This course is part one in a series of three courses for hands-on preparation for the Microsoft Certified Solutions Associate (MCSA) Exams 410, 411 and 412 that provides the skills and knowledge necessary to implement a core Windows Server 2012 infrastructure in an existing enterprise environment. The three courses collectively cover implementing, managing, maintaining and provisioning services and infrastructure in a Windows Server 2012 environment. Although there is some cross-over of skills and tasks across these courses, this course G1: helps students to get hands-on instruction and practice installing and configuring Windows Server 2012, including Windows Server 2012 R2. It maps directly to MCSA Exam 410 and focuses on the initial implementation and configuration of core services, such as Networking, Storage, Active Directory Domain Services (AD DS), Group Policy, File and Print Services, and Hyper-V. G2: introduces mobile device concept from CompTIA A+. Assessment scheme: 1) On-going assessment: 70% - 13 Labs: 40% - Participation in Discussions: 10% - 02 progress tests: 20% 2) Final Exam: 30% 3) Final Result: 100% Completion Criteria: 1) Every on-going assessment component >0 2) Average Lab Score >= 4 3) Final Exam Score >=4 & Final Result >=5
