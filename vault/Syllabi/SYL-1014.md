# SYL-1014

Subject: [[JPS132]]
Name: Tiếng Nhật sơ cấp 3
Credits: 3
Degree Level: Bachelor
Time Allocation: Contact time: 30 sessions; 1 session = 90'
Prerequisite: Must pass JPS12x
Active: True
Approved: True
Decision: 216/QĐ-ĐHFPT dated 03/29/2016

## Description
Nội dung học bao gồm: 1 Các bài học chính: 9 bài tiếp theo (Shin I: bài 17 – bài 25) - Từ và mẫu câu mới - Luyện tập cơ bản - Luyện tập ứng dụng - Luyện tập hội thoại - Nghe hiểu, đọc hiểu - Kiến thức phụ trợ, nâng cao 2. Chữ Hán: 70 chữ trong Shin Kanji Workbook 1 - part 1, 2 - Cách viết, cách đọc, cách ghép… - Luyện tập
