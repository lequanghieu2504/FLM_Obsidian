## Description
Learn front-end web development for implementing a multi-platform solution: - This subject introduces an overview of client-side web UI frameworks, in particular Bootstrap. The student will learn about grids and responsive design; Bootstrap CSS and JavaScript components; CSS preprocessors, Less and Sass. - The basics of Node.js and NPM and task runners like Grunt and Gulp. - Explores Javascript based front-end application development, and in particular the React library: JavaScript ES6 for developing React application, Reactstrap for Bootstrap based responsive UI design, React components, React router and its use in developing single-page applications, designing controlled forms. - The student will be introduced to the Flux architecture and Redux. Explore various aspects of Redux and use it to develop React-Redux powered applications. - Use Fetch for client-server communication and the use of REST API on the server side.
