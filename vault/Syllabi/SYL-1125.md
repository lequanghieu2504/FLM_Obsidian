## Description
Basic C ++ Programming is a course providing learners with the first basic programming skills to be able to program embedded applications. After completing the course, students are provided with knowledge and skills on basic concepts of C ++ programming language; Understand and use complex data structures of C ++; Be aware of functions and program organizations in C ++; Understand the concepts of object-oriented programming in C ++; Know how to work with and handle files in C ++
