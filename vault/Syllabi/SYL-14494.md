## Description
This course introduces students to the end to end machine learning lifecycle, focusing on the practices, tools, and culture of Machine Learning Operations (MLOps). Students will learn how to transition machine learning models from isolated experimental notebooks into production-ready, scalable, and continuously monitored software systems. The curriculum covers project scoping, data version control (DVC), automated data and model pipelines (TFX), containerization (Docker), continuous integration and continuous deployment (CI/CD), model serving architectures, and automated drift monitoring. By completing hands-on labs and a final capstone project, students will gain engineering skills to build reliable, reproducible, and automated AI systems.

| 2 | CLO2 | Execute machine learning project scoping, define business key performance indicators (KPIs), select appropriate deployment patterns, and establish reliable performance baselines. |
| 3 | CLO3 | Implement systematic error analysis, data-centric AI techniques, and experiment tracking to address issues like skewed datasets and class imbalance. |
| 4 | CLO4 | Build automated data pipelines utilizing version control tools (DVC) and centralized feature stores (TFX) to guarantee data lineage and experiment reproducibility. |
| 5 | CLO5 | Design and coordinate end-to-end machine learning orchestration pipelines utilizing components like TensorFlow Extended (TFX) for training, evaluation, and validation. |
| 6 | CLO6 | Apply containerization (Docker) and Continuous Integration/Continuous Deployment (CI/CD) workflows to automate model testing and infrastructure provisioning. |
| 7 | CLO7 | Deploy production-grade model serving microservices using architectures like FastAPI, TensorFlow Serving, and Kubernetes supporting progressive delivery patterns. |
| 8 | CLO8 | Construct automated production monitoring infrastructures with Prometheus, Grafana, and Evidently AI to detect data drift, concept drift, and performance degradation. |
| 9 | CLO9 | Architect, document, and present a complete, end-to-end operational MLOps system that solves a real-world enterprise problem. |
