## Description
Hands-on Embedded Systems Development: Learn to implement real-world embedded system projects on microcontrollers (using both simulation environments and physical hardware) with the STM32Cube HAL library and STM32CubeIDE. Peripheral Mastery & ARM Architecture: Master the core architecture of the ARM Cortex-M processor. Develop and refine C/C++ source code to build diverse applications (signal generators, temperature monitoring systems, audio players, and user interfaces) by leveraging Digital/Analog I/O, Interrupts, Timers, and Pulse-Width Modulation (PWM). Gain hands-on proficiency in analyzing and deploying serial communication protocols—SPI, UART, and I2C—while evaluating their advantages and limitations in embedded environments. Real-Time Operating Systems (RTOS): Explore the core characteristics of RTOS and multitasking mechanisms on microcontrollers. Students will directly apply Threads, Mutexes, Semaphores, and Interrupts to design a complete multitasking system, effectively resolving resource contention issues. Practical Engineering Skills: Prototype embedded systems using the ST Nucleo-F401RE (ST Nucleo-F411RE) development board and cost-effective components. Enhance hardware-level C/C++ programming mindsets by immediately applying theory to practice. Master the end-to-end hardware development workflow alongside professional debugging and troubleshooting techniques.
