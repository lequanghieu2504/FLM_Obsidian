## Description
Upon finishing the course, students can: 1) Knowledge: Understand (ABET e) - the connection between data structures and their algorithms, including an analysis of algorithms' complexity; - data structurre in the context of object-oriented program design; - how data structure are implemented in an OO programming language such as Java 2) Able to (ABET e) - organize and manipulate basic structures: array, linked list, tree, heap, hash - use algorithms for traversing, sorting, searching on studying structures - select a suitable algorithm to solve a practical problem 3) Able to (ABET k) - use JAVA programming language for solving some problems - use Eclipse tool for developing programs in JAVA - Implement some programs in JAVA to solve practical problems based on the studying algorithms 4) Others: (ABET i) - Improve study skills (academic reading, information searching, ...)
