# SYL-11273

Subject: [[ANC301]]
Name: Character Development_Tạo hình nhân vật hoạt hình
Credits: 3
Degree Level: Bachelor level
Time Allocation: Study hour (150h) = 45h contact hours + 105h self-study
Prerequisite: DRD20x or IPD201
Active: True
Approved: True
Decision: 358/QĐ-ĐHFPT dated 04/03/2024

## Description
Students will work on specific character development skills necessary to work in the animation industry. Students will also be exposed to animating and cleaning up ‘on model’ from existing and created model sheets

## Learning Outcomes
| No. | CLO Name | CLO Details |
| --- | --- | --- |
| 1 | CLO1 | Know the basics of Animation films. |
| 2 | CLO2 | Define what is a cartoon. |
| 3 | CLO3 | Know the process of producing an Animation film. |
| 4 | CLO4 | Understand the role and responsibility of a cartoon artist in film making. |
| 5 | CLO5 | Understand how to build characters for an animated movie |
| 6 | CLO6 | Be able to draw a size comparison chart for characters. |
| 7 | CLO7 | Draw details of main-characters, sub-characters and coloring them. |
| 8 | CLO8 | Creating a character turnaround sheet. |
| 9 | CLO9 | Drawing action poses and facial expressions of characters |
