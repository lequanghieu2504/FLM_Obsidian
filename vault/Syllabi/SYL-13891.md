# SYL-13891

Subject: [[PRN212]]
Name: Basis Cross-Platform Application Programming With .NET_Lập trình ứng dụng đa nền tảng cơ bản với .NET
Credits: 3
Degree Level: Bachelor
Time Allocation: Study hour (150h) = 49.5h contact hours + 145 minute final exam + 98.1h self-study
Prerequisite: [[PRO192]], [[DBI202]]
Active: True
Approved: True
Decision: 1402/QĐ-ĐHFPT dated 12/12/2025

## Description
Upon completion of this course students should: 1. Understand the followings: • C# language for developing .NET applications; • Fundamental concepts of .NET Platform • Basic knowledge of Windows Presentation Foundation in .NET 2. Be able to: • Develop Cross-platform Desktop applications and support for user experience ( UI & UX ) 3. Be able to work in a team and present group's results

## Learning Outcomes
| No. | CLO Name | CLO Details |
| --- | --- | --- |
| 1 | CLO1 | Describe about .NET Core Platform, and more new features of C# language . |
| 2 | CLO2 | Demonstrate about OOP , Generic, Delegate & Event , LINQ and Design Pattern in C# |
| 3 | CLO3 | Demonstrate about Windows Presentation Foundation |
| 4 | CLO4 | Demonstrate about accessing to the database by Entity Framework ( ORM ) |
| 5 | CLO5 | Explain about Concurrency programming, Stream I/O |
| 6 | CLO6 | Apply Generative AI tools to support software development tasks in .NET |
