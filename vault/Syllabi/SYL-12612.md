## Description
This course will introduce fundamental modern information and system protection technology and methods, develop a lifelong passion and appreciation for cyber security.

## Learning Outcomes
| No. | CLO Name | CLO Details |
| --- | --- | --- |
| 1 | CLO1 | Explain underlying concepts related to common cyber security threats, vulnerabilities, and risks. |
| 2 | CLO2 | Explain basics of cyber defense starting with foundational models such as Bell-LaPadula and information flow frameworks. |
| 3 | CLO3 | Explain real-time cyber security techniques and methods in the context of the TCP/IP protocol suites. |
| 4 | CLO4 | Summary advanced and current topics in cyber security, many of which are especially relevant in modern enterprise and infrastructure settings. |
