## Description
The course is to provide students with practical knowledge in ES field: 1. Introduction of Embedded System 2. Using circuit design and simulation softwares 3. Programming Essentials 4. uC hardware 5. Digital I/O interface 6. Timer and Interrupt 7. Compare and capture 8. Analog Interface 9. Power outputs 10. Serial communication 11. Sensor interfacing 12. Practicing with PICkit2 of Microchip 13. Analyzing some practical projects This course will comprehensively guide to interfacing microcontrollers based on the I/O devices of the PIC 16F877 chip, including keypads, displays, analogue, timers and a full range of serial peripherals. Each interface is explained in detail by means of fully operational, interactive demonstration application using Proteus VSM design and simulation. Each demo application can be viewed by chapter – schematic, design file, source code and operational description Assessment scheme: 1) On-going asessment: 60% - 02 Assignments: 2x15%=30% - 01 quiz: 20% - Lab activities: 10% 2) Final Exam: 40% 3) Final Result: 100% Completion Criteria: 1) Every on-going assessment component >0 2) Final Exam Score >=4 & Final Result >=5
