## Description
This course aims to provide three methods for linear programming and apply them to solve the practical problems. After completing this course, students should know how to model some types of practical problems as a linear program and apply the provided methods for addressing them. Topics covered in this course are primal and dual simplex methods, interior point method for linear programs with continuous variables and Branch-and-Bound method for the linear programs with integer variables. Applications of these methods for dealing with various types of practical problems are also included. Teaching and learning method: Lecture, Project based learning, Problem based learning, flipped classroom,....
