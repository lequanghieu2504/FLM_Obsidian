## Description
This course provides an introduction to these areas below: - Provides an introduction to interaction design - How theory and research findings have been applied to interaction design. - Comprehensive view of the various interface design - Data gathering, analysis, interpretation and presentation in Interaction Design - Techniques for establishing requirements, prototyping and design - Various approaches to evaluation design Assessment scheme: 1) On-going Assessment: - At least 3 progress tests: 25% - 02 Assignments: 30% - 01 presentation: 5% 2) Final exam: 40% (ABET c) 3) Final Result: 100% Completion Criteria: 1) Every on-going assessment component >0 2) Final Exam Score >=4 & Final Result >=5
