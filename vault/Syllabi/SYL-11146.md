## Description
This course covers the fundamentals of working in CG (Computer Graphics) with Maya. It provides an overview of maya, basic modeling tools, working with UVs, textures,basic lighting and rendering using the provided software.

## Learning Outcomes
| No. | CLO Name | CLO Details |
| --- | --- | --- |
| 1 | CLO1 | Apply different modeling techniques in Maya: Poly modeling, Subdivision modeling and NURBS modeling |
| 2 | CLO2 | Understand topology and apply it appropriately. |
| 3 | CLO3 | Create a 3D character model that’s proper for aimation |
| 4 | CLO4 | Create and modify material in Maya |
| 5 | CLO5 | Setup lighting, camera and render a scene using Arnold Renderer |
| 6 | CLO6 | Having a positive attitude and a professional working style |
