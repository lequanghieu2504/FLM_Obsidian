## Description
This course tackles all the problems related to NodeJS-based web servers. Contents to be implemented include: - Overview of Web protocols: HTTP and HTTPS. - Introduction of NodeJS and NodeJS: Express modules to build a web server. - Deploy the application on a web server with basic CRUD operations. Work with NoSQL databases, specifically MongoDB and Mongoose, to access MongoDB from NodeJS. - Overview of REST and building a RESTful API. - Learn Authentication and security-related issues for web applications.
