## Description
This course provides an immersive learning experience in the field of web application security, featuring the use of PortSwigger as our primary lab material. PortSwigger offers a powerful platform for hands-on exploration of web application vulnerabilities and security best practices. Through this course, students will gain a deep understanding of web application security principles and develop practical skills in a controlled, real-world environment.

## Learning Outcomes
| No. | CLO Name | CLO Details |
| --- | --- | --- |
| 1 | CLO1 | Gain an introductory understanding of web security principles and their importance in the context of web applications. |
| 2 | CLO10 | Develop the skills to identify and exploit race conditions, especially related to limit overruns. |
| 3 | CLO11 | Understand the concept of path traversal vulnerabilities and how they can be exploited. |
| 4 | CLO12 | Gain the skills to identify and exploit vulnerabilities related to file uploads. |
| 5 | CLO2 | Understand the concept of information disclosure vulnerabilities and their potential impact on web application security. |
| 6 | CLO3 | Examine vulnerabilities in various authentication mechanisms (password-based and multi-factor authentication). |
| 7 | CLO4 | Learn how to identify, exploit IDOR and Privilege escalation. |
| 8 | CLO5 | Explore vulnerabilities related to OAuth 2.0 authentication mechanisms. |
| 9 | CLO6 | Understand SQL injection vulnerabilities and their exploitation. |
| 10 | CLO7 | Understand OS Command Injection vulnerabilities and their exploitation. |
| 11 | CLO8 | Learn to identify and exploit reflected XSS vulnerabilities. |
| 12 | CLO9 | Understand SSRF vulnerabilities and the potential risks they pose. |
