## Description
In this course, students will learn core programming concepts that apply to lots of programming languages, including C#. They will build their foundational C# and Unity knowledge by exploring C# and Unity topics. They will also learn how to apply that knowledge for developing and completing some their games.

## Learning Outcomes
| No. | CLO Name | CLO Details |
| --- | --- | --- |
| 1 | CLO1 | Know how to write your first C# console application and Unity script and know how to store data in programs |
| 2 | CLO2 | Know how to use classes and objects to implement code |
| 3 | CLO3 | Know the basics of Unity 2D games and know how to make decisions in code |
| 4 | CLO4 | Know how to get and use player input in Unity games |
| 5 | CLO5 | Know how to store lots of data in arrays and lists and use iteration (looping) to repeat actions in code |
| 6 | CLO6 | Understand about abstraction and know how to use it to design and implement console application classes |
| 7 | CLO7 | Know how to use abstraction to design and implement Unity classes |
| 8 | CLO8 | Know how to add text output and sound effects to Unity games |
