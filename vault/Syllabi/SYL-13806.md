# SYL-13806

Subject: [[MSS301]]
Name: Microservices with Spring Cloud_Microservices với Spring Cloud
Credits: 3
Degree Level: Bachelor
Time Allocation: Study hour (150h) = 45h contact hours + 145-minute final exam +102.6h self-study
Prerequisite: SBA301
Active: True
Approved: True
Decision: 1402/QĐ-ĐHFPT dated 12/12/2025

## Description
Upon completion of this course students shoud: 1. Understand the followings: • Microservices, Microservices architecture. • The basics of Spring Cloud and its architecture • The configuration and implementation using Spring Cloud • The microservices architecture using Spring Cloud. • The deployment of microservices-based applications using Docker and Spring Cloud tools 2. Be able to: • Explain about Microservices architecture and its benefits, including scalability, resilience, and fault tolerance. • Explain about Spring Cloud and its architecture • Configure and implement Spring Cloud in a project • Design and implement a microservices architecture using Spring Cloud • Design, build, and deploy microservices-based applications using Docker and Spring Cloud tools 3. Be able to work in team and present group's results
