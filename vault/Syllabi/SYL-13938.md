## Description
_ This course provides English major students with an insight to Outcome-based education with the implementation of Project-based learning, which aims to develop a mindset of more student-centered approaches. _ Teaching methods/Pedagogical approaches: * Project-Based Learning * Problem-Based Learning * Task-Based Language Teaching * WebQuest-Based Learning * Flipped Classroom * Jigsaw Method * Tool-Based Pedagogy * Prototype-Based Learning * Constructivist Approach * Inquiry-Based Learning / Guided Inquiry / Scaffolded Inquiry * Discovery Learning * Collaborative Learning / Collaborative Brainstorming / Collaborative Inquiry * Case-Based Learning * Practice-Based Learning * Direct Instruction * Workshop-based Learning * Digital Literacy Pedagogy _ Teaching formats & activity types: Lecture + project work + AI-integrated learning activities

## Learning Outcomes
| No. | CLO Name | CLO Details |
| --- | --- | --- |
| 1 | CLO1 | Analyze the principles and benefits of OBE in teaching English as a foreign language by comparing traditional and outcome-based approaches using AI research tools (NotebookLM, ChatGPT, Gemini, Claude) to synthesize educational literature and generate comparative frameworks. |
| 2 | CLO2 | Design the alignment between learning outcomes, instructional methods, and assessment strategies in an OBE framework utilizing AI-powered educational tools (MagicSchool AI, Eduaide.AI) to create coherent curriculum maps and alignment matrices. |
| 3 | CLO3 | Develop measurable and achievable learning outcomes for an EFL course using Bloom's taxonomy and SMART criteria with AI assistance (ChatGPT, Gemini) for language precision, clarity checking, and taxonomy alignment verification. |
| 4 | CLO4 | Evaluate the effectiveness of project-based learning activities in achieving specific learning outcomes within an OBE context by analyzing AI-generated data (adaptive learning platforms, Mentimeter analytics) and student engagement metrics |
| 5 | CLO5 | Create an authentic, outcome-aligned project proposal for EFL learners, including timeline, resources, and success criteria using AI content creation tools (MagicSchool AI, Canva AI) for multimedia resources and differentiated materials |
| 6 | CLO6 | Apply formative and summative assessment principles to design assessment tools that measure learning outcome achievement leveraging AI assessment generators and automated rubric creators for efficient, fair evaluation systems |
| 7 | CLO7 | Construct detailed rubrics with clear performance criteria and proficiency levels for project-based assessments using AI-powered rubric generators and natural language processing tools for precise criterion definition |
| 8 | CLO8 | Demonstrate effective collaboration skills by contributing meaningfully to group project implementation and peer feedback processes facilitated by AI collaboration platforms (Google Workspace AI, Microsoft Copilot) for enhanced communication and project management |
| 9 | CL09 | Evaluate the ethical implications and limitations of AI tools in educational settings by analyzing bias, privacy, and pedagogical effectiveness in EFL contexts |
| 10 | CL10 | Apply AI translation and language processing tools to develop inclusive, multilingual educational resources for diverse EFL classroom environments |
