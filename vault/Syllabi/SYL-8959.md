## Description
The course is to provide students with practical knowledge in ES field: 1. Introduction to Embedded System Development 2. Embedded Software Development Tools 3. Embedded Software Architectures 4. Optimizing Embedded Code 5. Opensource Operating System (Linux) 6. Real-Time Operating Systems 7. Opensource Programming 8. ARM Architecture & Porting OS 9. Setting Up Your Embedded Linux Development 10. Development a simple applications on ARM based Linux 11. Practicing on Embedded Computer 12. Testing techniques for embedded systems & Managing embedded development projects 13. Advanced embedded systems topics Assessment scheme: 1) On-going asessment: - 01 Assignment: 20% - 02 quizzes: 30% - Lab activities: 10% 2) Final Exam: 40% 3) Final Result: 100% Completion Criteria: 1) Every on-going assessment component >0 2) Final Exam Score >=4 & Final Result >=5
