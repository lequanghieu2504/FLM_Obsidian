## Description
This course provides the knowledge and skills of Object Oriented Programming using the Java Programming Language.

## Learning Outcomes
| No. | CLO Name | CLO Details |
| --- | --- | --- |
| 1 | CLO1 | Understand the concepts of object oriented (OO) programs to solve problems and fundamentals of object-oriented programming in Java |
| 2 | CLO2 | Practice basic Java language syntax and semantics to write Java programs and use concepts such as variables, conditional and iterative execution methods |
| 3 | CLO3 | Uses streams to read and write data from/to different types of sources/targets |
| 4 | CLO4 | Discuss the benefits and the use of JAVA’s Exceptional handling mechanism |
| 5 | CLO5 | Identify classes, objects, members of a class and relationships among them needed for a specific problem |
| 6 | CLO6 | Explain the concept and demonstrates the use of Polymorphism, Encapsulation, Abstraction and Inheritance in java |
| 7 | CLO7 | Discuss the principles and the use of abstract classes and interfaces in java |
| 8 | CLO8 | Be able to design and implement a complete program - console application |
| 9 | CLO9 | Explain the principles and the use of some (java collections) abstract data types (list, set, map) |
