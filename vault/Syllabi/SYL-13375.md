## Description
Students will continue developing design skills for web, with a focus on typography, UI design, and use digital design tools to create graphic elements and content. Emphasis will be on critical thinking, executing design strategies and concepts, and comprehensive creative solutions to design problems in the web and mobile space.

## Learning Outcomes
| No. | CLO Name | CLO Details |
| --- | --- | --- |
| 1 | CLO1 | Explain the core principles of user experience (UX) design and identify key factors that attract users to a website. Formulate essential research questions that guide early-stage design decisions. |
| 2 | CLO2 | Conduct effective project planning through efficient meetings, clearly defined objectives, and a well-understood approval process. |
| 3 | CLO3 | Define and prioritize clear, actionable project requirements based on input from both business stakeholders and target users. |
| 4 | CLO4 | Research and analyze user needs, and integrate user perspectives throughout all stages of the design process. |
| 5 | CLO5 | Choose and utilize the tools and techniques that enable you to bring visual ideas to your project team quickly |
| 6 | CLO6 | Understand the fundamentals of design systems and apply them to maintain consistency across UI components, layouts, and styles. |
| 7 | CLO7 | Be able to use design tools to create clean and well-structured UI for common design patterns |
