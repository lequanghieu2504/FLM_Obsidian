## Description
This course covers the fundamentals of creating 3D character UVs, creating textures with Substance Painter, and working with lighting and rendering. Substance Painter is clearly a very powerful texture drawing software. It helps 3D Artists to draw textures in a simpler & more intuitive way based on the available intelligent material inventory Mastering this software also helps 3D Artist understand the properties of each material, thereby easily combining with other 3D software.
