## Description
This course is designed to further develop the learner's confidence and fluency in using the English language and to enrich their learning experience through interactive lessons and communicative exercises. 1) On-going assessment - Progress test: 02*20%: 40% - Presentation: 20% 2) Final Examination (FE) 40% 3) Final Result 100% 4) Completion Criteria: a) On-going assessment >0, Final Exam Score >=4/10 & Final Result >=5/10 b) Each part of final exam must be >0. - If FE < 4/10, student must take resit exam (all parts); - If have a) but not b), student must take resit exam for the failed parts only
