## Description
- Knowledge about data analysis concept, primary methods and processes, and analysis skills has become an essential part of an education in information system because main objectives of information systems are to support for enterprize's business. The data analysis is an very important aspect for making operation effectiveness of enterprize

## Learning Outcomes
| No. | CLO Name | CLO Details |
| --- | --- | --- |
| 1 | CLO1 | Understand the data analysis concepts and primary methods (Time Series Analysis, Classification, Regression, Clustering, Association Rules….) |
| 2 | CLO2 | Understand basic process in data analytics |
| 3 | CLO3 | Understand how to clean, and organize data for analysis, evaluate, and complete analysis and calculations using spreadsheets, SQL, R programming or Python |
| 4 | CLO4 | Design database schemas based on the conceptual model by using appropriate tools (spreadsheets, SQL, R programming, Tableau or Python) |
| 5 | CLO5 | Visualize and present data findings in dashboards, presentations and commonly used visualization platforms |
