## Description
1. Class attendance is strongly encouraged. Attend more than 80% of class hours in order to be accepted to the final examination 2. Actively participate in class activities 3. Fulfill tasks given by instructor after class 4. Use their own laptop in class only for learning purpose 5. Read the textbook in advance 6.
