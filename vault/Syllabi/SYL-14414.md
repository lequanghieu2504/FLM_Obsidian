## Description
GNS301 is an intensive course designed to bridge the gap between game development and backend engineering. You will master the "hidden" infrastructure of online gaming—from raw data transmission and latency optimization to scalable server architectures. By the end of this course, you will be able to build secure, high-performance multiplayer environments capable of supporting real-time global interactions. Key Learning Outcomes: - Master Low-Level Networking: Build custom servers using TCP and Reliable UDP (LiteNetLib). Learn to handle raw sockets and binary serialization for maximum bandwidth efficiency. - Combat Latency: Implement industry-standard lag-compensation techniques, including Client-side Prediction, Interpolation, and Server Reconciliation to ensure smooth gameplay. - Architect Scalable Systems: Apply professional 3-Layer Architecture (Presentation, Logic, Data) to backend development. Integrate MongoDB for persistence and Docker for containerized deployment. By the end of this course, you will have the skills to architect and develop a complete multiplayer ecosystem. You will possess the technical confidence to build not just a game, but a secure, scalable, and professional server infrastructure capable of delivering seamless real-time experiences to a global audience.
