## Description
Upon finishing the course, students must acquire: 1. the following knowledge: (ABET a1) • Fundamental concepts of Digital Image Processing. • Basic image processing operation. 2. the following skills: (ABET a2) • Image analysis algorithms. • Current applications in the field of digital image processing. • Fundamental concepts and basic functions in Tensorflow. • Using Tensorflow in image processing

## Learning Outcomes
| No. | CLO Name | CLO Details |
| --- | --- | --- |
| 1 | CLO1 | Explain how digital images are represented and manipulated in a computer, including reading and writing from storage, and displaying. |
| 2 | CLO2 | Write a program which implements fundamental image processing algorithms. |
| 3 | CLO3 | Be conversant with the mathematical description of image processing techniques and know how to go from the equations to code. |
| 4 | CLO4 | An ability to apply knowledge and identify the computing requirements appropriate for its solution. |
| 5 | CLO5 | An ability to design, implement and evaluate a computer-based system, process, component or program to meet desired needs. |
| 6 | CLO6 | An ability to apply mathematical foundations, algorithmic principles and computer science theory to the modeling and design of computer based systems in the way that demonstrates comprehension of the tradeoffs involved in design choices. |
| 7 | CLO7 | An ability to use all the main functions of Tensorflow and understand how to apply them to process a problem in image processing. |
| 8 | CLO8 | An ability to understand the advantages and disvantages of Tensorflow in comparison with other image processing's frameworks (OpenCV, Keras, etc...). |
