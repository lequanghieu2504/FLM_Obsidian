## Description
Description: This course aims to provide students with knowledge related to Interaction and UX, Ui Design in the mobile world including smartphone devices and other wearable devices. In this course, students will be taught the common principles that prevail in mobile interface design in general. Specific guidelines corresponding to three popular mobile platforms such as Android, iOS and Windows will also be discussed. A nimble tool for Interaction and UX research and design, Ui in Mobility will also be introduced and applied through this course. At the end of this course, students will gain practical experience through a project that has phases: research, user segmentation, user persona, userflow, wireframe, Agile Project Management ..., in which they must apply principles have learned. This course will help students perfect the app.
