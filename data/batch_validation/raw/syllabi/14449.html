Syllabus ID: 14449
Syllabus Name: AI for Cybersecurity_Trí tuệ nhân tạo cho An ninh mạng
Course Name English: AI for Cybersecurity
Subject Code: AIC211
Learning-Teaching Method: Offline
NoCredit: 3
Degree Level: Bachelor
Time Allocation: Study hour (150h) = 45h (60 sessions) contact hours + 1h final exam + 104h self-study
Pre-Requisite: PFP191, MAE101
Description: This course provides foundational knowledge of machine learning (ML) and AI techniques for solving cybersecurity problems. The content focuses on modeling security challenges as machine learning problems, processing and representing cybersecurity data (system logs, network traffic, security events, endpoint telemetry), and building and evaluating models. This ultimately supports the tracking, monitoring, detection, and prevention of cyber threats to protect data and systems.

The module combines theoretical foundations (basic concepts of supervised/unsupervised learning, classification, regression, anomaly detection, model evaluation, overfitting, and ML pipelines) with hands-on Python labs using popular libraries in the cybersecurity domain (such as scikit-learn and introductory deep learning modules). Students will work with real-world cybersecurity datasets applied to tasks such as Intrusion Detection Systems (IDS), malware classification, phishing URL/email detection, and user/system behavior anomaly detection.
Upon completion of this course, students will be able to:

1. Understand and explain the fundamental concepts of machine learning and how to map them to cybersecurity problems.

2. Design and deploy simple, end-to-end machine learning pipelines: data collection, preprocessing, feature extraction/engineering, training, evaluation, and model improvement for cybersecurity tasks.

3. Apply machine learning techniques to predict attack behaviors, detect vulnerabilities/anomalous activities, and support decision-making in secure system operations.

4. Build a solid foundation for advanced courses in malware analysis, threat hunting, SOC engineering, and AI system security, while gaining practical experience in developing machine learning solutions for digital security.

1 CLO1 Understand the Principles of AI/ML/DL Grasp the core concepts, the distinctions between Supervised and Unsupervised Learning, fundamental Neural Network architectures, and the standard workflow for building a foundational machine learning model.
2 CLO2 Understand the Cybersecurity Context Comprehend how AI is integrated into security architectures and identify specific cybersecurity challenges that are suitable for AI-driven solutions.
3 CLO3 Apply Basic Probability and Statistics Apply fundamental concepts of probability and statistics to model and analyze cybersecurity data, including estimating the likelihood of attack events and evaluating the reliability and statistical significance of detection results.
4 CLO4 Apply Exploratory Data Analysis (EDA) and Feature Engineering Utilize programming tools (Python/Pandas) to collect, explore, and visualize cybersecurity data (such as system logs and network traffic). Execute data preprocessing and feature engineering techniques—including data cleaning, encoding, and feature extraction—to adequately prepare input data for machine learning models.
5 CLO5 Apply Supervised and Unsupervised Learning Implement supervised and unsupervised machine learning algorithms to develop models for intrusion detection, malware classification, and anomaly detection.
6 CLO6 Apply Deep Learning and NLP for Security Leverage Natural Language Processing (NLP) techniques to analyze and detect deceptive content, such as phishing and spam, within text and URLs.
7 CLO7 Performance Analysis Analyze experimental results using a Confusion Matrix and key performance metrics (Precision, Recall, and F1-score), evaluating the operational impact of False Positives and False Negatives in real-world security environments.
8 CLO8 Apply Imbalanced Data Handling Employ data preprocessing techniques, such as resampling and class weighting, to resolve challenges associated with imbalanced datasets.
9 CLO9 Analyze AI Risks and Apply LLMs in Cybersecurity Analyze model vulnerabilities, specifically adversarial attacks, and evaluate emerging threats introduced by Generative AI, such as deepfakes and automated social engineering. Furthermore, apply Large Language Models (LLMs) and agentic AI frameworks to address and resolve complex cybersecurity challenges.
10 CLO10 Apply Project Development Synthesize acquired knowledge and utilize collaborative teamwork skills to design, implement, and present an end-to-end AI pipeline addressing a real-world cybersecurity problem.
